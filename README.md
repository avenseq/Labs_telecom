# ThinkDSP Labs

Лабораторные работы по учебнику Think DSP.

## Содержание

В репозитории собраны лабораторные работы по главам книги Think DSP.
Для каждой главы создана отдельная папка с Jupyter Notebook.

## Структура проекта

- `Lab1/` — глава 1
- `Lab2/` — глава 2
- `Lab3/` — глава 3
- ...
- `Lab11/` — глава 11

## Установка зависимостей
